First-time setup

A minute to settle in.

Gridlet runs in your menu bar. It needs Accessibility permission to move and resize other apps’ windows.

  1. Download and move to Applications

    Unzip the download, then drag Gridlet into your Applications folder and open it.

  2. Check the beta’s first-launch notice

    This release has a local signature, not an Apple Developer ID signature or notarization. If macOS blocks it, review Apple’s guide to opening Mac apps safely. Only open software you trust.

  3. Enable Accessibility

    Click Accessibility… in Gridlet. In System Settings → Privacy & Security → Accessibility, add Gridlet and turn it on.

  4. Pick a window. Pick a place.

    Click the window you want to arrange, press Command–Shift–D, and drag across the grid. The menu bar grid icon works too.

A small, early release

Some apps enforce a minimum window size. Exit macOS full-screen mode before arranging windows. If another utility already uses Command–Shift–D, Gridlet will show a shortcut warning.

There are no saved layouts or automatic updates yet. Intel and older macOS versions are included as build targets; testing so far is on an Apple silicon Mac.

Your desktop stays yours

Gridlet does not collect analytics, record your screen, or send data over the network. Its Accessibility access is used to read and change window position and size.
